# Sobre o projeto
O projeto visa a criação de um prgrama que cadastre individuos, sendo eles alunos de alguma escola, atravez da sua biometria facial, sendo preciso cadastrar e deixar arquivado uma foto do rosto de maneira centralizada para o programa entender, dos individuos em questão, nomes e informado a turma que ele sera cadstrado, visando assim um programa que facilite a presenca e o cadstro destes alunos.

# Ferramentas ultilizadas
Pode-se destacar algumas ferramentas ultilizadas durante a criação do projeto, como sendo de grande importância o uso de Javascript, HTML, CSS e React.

# Reconhecimento facial
O projeto ultiliza de uma biblioteca face-api.js para fazer o reconhecimento facial.
